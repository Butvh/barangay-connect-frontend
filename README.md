# Barangay Connect

Responsive, offline-first frontend for a fictional barangay disaster-response demo. Plain HTML, CSS and JavaScript ES modules. No build step.

## Development

Serve with XAMPP Apache at http://localhost/barangay-connect/resident-login.html. GitHub repository setup is pending GitHub CLI authentication.

Person 2 owns the resident pages, shared UI foundation and illustrated map. Person 1 owns data/auth, official pages, Profile, checks and deployment workflows.
